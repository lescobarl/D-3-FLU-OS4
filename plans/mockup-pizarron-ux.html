📌 Resumen de los cambios de diseño/UX

  • Tarjetas plegables: cada sección (respuesta, imagen, horario, análisis, subida) es una tarjeta que se puede abrir/cerrar. Solo se muestran las que tienen contenido, evitando el "Sin contenido" repetido.
  • Confirmación visual: al agregar una clase al horario aparece un mensaje "✓ Clase agregada" para que sepas que funcionó.
  • Errores claros: si falla la lectura de una imagen, se explica qué pasó y qué hacer (en vez de un mensaje genérico).
  • Zona de subida destacada: se resalta con borde de color para que sea fácil de encontrar.
  • Badges informativos: el horario muestra cuántas clases tiene ("3 clases") para dar contexto de un vistazo.
